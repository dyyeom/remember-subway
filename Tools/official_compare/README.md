# 공식 역 자료 대조 도구

앱 역 데이터(`RememberSubway/Resources/transit_data.json`)를 공공데이터포털(data.go.kr) 파일과 하나씩 맞춰 본다.
역 데이터 자체는 `Tools/build_transit_data.swift`에서 고치고 다시 생성한다. JSON은 직접 고치지 않는다.

```sh
python3 -I Tools/official_compare/fetch.py DL_DIR PK [PK...]   # compare.py에 적힌 PK 파일 내려받기
python3 -I Tools/official_compare/compare.py RememberSubway/Resources/transit_data.json DL_DIR
```

- `compare.py`: 노선별로 자료마다 앱에 없음 / 자료에 없음 / 이름 / 순서(비인접) / 역명 변경 후보를 출력한다.
  마지막에 모든 노선의 **역명 변경 후보(시행 확인 필요)**를 따로 모아 보여 준다.
- `extra.json`: 공식 파일이 없는 노선의 보조 자료와 대조 예외.
  - `_exclude`: 자료에 있어도 앱에 넣지 않기로 확정한 역(예: 미개통역). `{"line": {"역명": "사유"}}`
  - `_unconfirmed_renames`: 공공데이터에만 바뀐 이름이 보이고 실제 시행은 확인되지 않은 역명.
    `{"line": {"자료 역명": {"app": "앱 역명", "reason": "사유"}}}`. 대조 때 자료 이름을 앱 이름으로 읽고
    `보류`로만 표시한다.

## 역명 변경 반영 규칙

1. **공공데이터에서만 차이가 보이는 역명 변경은 바로 반영하지 않는다.** 국가철도공단 등 공공데이터는
   예정 역명을 미리 싣거나 갱신이 늦는 경우가 있다(예: 신길온천 → 능길은 2026-06 자료에 실렸으나 2026-10 현재 미시행).
2. 다음 가운데 **하나 이상으로 실제 시행이 확인된 경우에만** 반영한다.
   - 운영기관 공지(역명 변경 안내, 노선도, 운영기관이 직접 낸 데이터의 변경 설명)
   - 지자체·국토교통부 고시
   - 시행(안내방송·역명판 교체 등)을 전한 언론 보도
   추진·심의 단계 보도("바꾸기로", "추진")만으로는 반영하지 않는다.
3. 반영할 때는 옛 이름을 별칭으로 남겨 정답으로 인정하고, 역 ID는 유지한다. 커밋 메시지에 근거 URL을 적는다.
4. 시행이 확인되지 않으면 앱 이름을 그대로 두고 `extra.json`의 `_unconfirmed_renames`에 사유와 함께 등록한다.
   나중에 시행이 확인되면 예외를 지우고 2·3번대로 반영한다.
5. 부역명 차이도 같은 원칙을 따른다. 다만 운영기관 자체 자료(역주소·역정보 파일 등)에 이미 실린 부역명은
   운영기관 자료로 본다. 유료 역명병기(기업·기관이 비용을 내고 붙인 이름)는 반영하지 않는다.
