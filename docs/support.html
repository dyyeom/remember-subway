사이역

지원

사이역은 이전 역과 다음 역 사이의 역 이름을 맞히는 지하철역 암기 게임입니다. 궁금한 점이나 문제가 있으면 아래 내용을 먼저 확인해 주세요.

자주 묻는 질문

정답을 맞게 입력했는데 오답으로 나와요.

공식 역명, 괄호를 포함한 전체 역명, 검수된 별칭만 정답으로 인정합니다. 띄어쓰기, 문장부호, 끝의 “역”은 무시합니다. 오타는 정답으로 인정하지 않습니다. 실제 역명과 다르다고 생각되면 노선, 이전 역, 다음 역을 적어 문의해 주세요.

점수는 어떻게 계산되나요?

정답은 100점, 초성 힌트를 쓰면 50점에서 시작합니다. 문제당 제한 시간은 15초이며, 남은 시간이 10초 미만이면 0초까지 초당 10%씩 점수가 줄어듭니다.

멀티플레이 방이 보이지 않거나 들어갈 수 없어요.

  • 모든 기기가 같은 Wi‑Fi에 연결되어 있거나 서로 가까이 있는지 확인해 주세요.
  • 설정 앱 › 개인정보 보호 및 보안 › 로컬 네트워크에서 사이역이 켜져 있는지 확인해 주세요.
  • “방장과 앱 버전이 달라요” 안내가 나오면 모든 기기를 최신 버전으로 업데이트해 주세요.
  • 한 방에는 방장을 포함해 최대 8명이 참가할 수 있고, 경기가 시작된 뒤에는 새로 들어갈 수 없습니다.

Game Center 랭킹에 점수가 올라가지 않아요.

Game Center에 로그인되어 있어야 점수가 제출됩니다. 0점 기록은 제출하지 않으며, 네트워크 문제로 실패한 기록은 기기에 보관했다가 다시 제출합니다.

인터넷 없이도 할 수 있나요?

네. 노선 데이터가 앱에 들어 있어 싱글플레이는 인터넷 없이 이용할 수 있습니다. 멀티플레이는 인터넷 대신 근처 기기와 로컬 네트워크로 연결합니다.

문의하기

버그 제보, 역 정보 오류, 기능 제안은 dyyeom@gmail.com로 보내 주세요. 사용 중인 iPhone 모델, iOS 버전, 노선 데이터 버전(앱의 설정 화면에서 확인)을 함께 적어 주시면 빠르게 확인할 수 있습니다.
